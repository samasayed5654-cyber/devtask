# DevTask — Programmer's To-Do App

A beautiful, programmer-themed task manager with calendar view, priority management, and dark terminal UI.

## Features

- 📋 **Dashboard** — Today's tasks, upcoming, priority breakdown, activity log
- 📅 **Calendar View** — Monthly calendar with color-coded tasks by priority
- ✅ **Task Management** — Create, edit, delete with priorities & tags
- 🔍 **Search & Filter** — Find tasks instantly, filter by status, sort by date/priority
- ⌨️ **Keyboard Shortcuts** — `N` new task, `1/2/3` switch views, `/` search
- 💾 **Local Storage** — All data persists in your browser

## Tech Stack

Pure HTML + CSS + JavaScript. No frameworks, no dependencies.
